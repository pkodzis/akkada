akk@da

akk@da is a simple network monitoring system designed for small and middle size computer networks. Its purpose is to quick detect system or network fault and to display information about detected problem for administrator. akk@da is designed as a pro-active network monitor. It does not wait for information from any agents, systems, etc. It collects information itself every single minute (you can decrease this period even to 1 second if you need). Almost all services of the monitored hosts are discovered automatically.
