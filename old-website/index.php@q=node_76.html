v 0.68

Submitted by Piotr Kodzis on Sat, 2006-02-04 23:13.
  • changes

[* fixed; + added; - removed; @ changed]

* probe tcpip discover process was added service even if it was unavailable on discovered host

+ probe node detection of new vendors: ibm, intel, brocade, novell, apc

@ probe node vendor detection: now is based on sysObjectsID, if its not enaught, it uses keys; some changes in ${AKKADA}/etc/conf.d/Probes/node.conf configuration file

+ GUI new plugins base on HOST-RESOURCES SNMP MIB: processes (lists system processes), devices (lists system devices), software (lists installed software)

+ probe cisco_dial_peer_voice for collecting VoIP statistics

* form_history_clear_log wasn't work with option "clear all log"

* probe bgp_peer tab "stat" made "internal server error"

+ tab "stat" hide/show each graph possibility

* tree_cache - problems with deleting and moving nodes

* tree_cache - alarms approval - problem with cache consistency, performance improved

* GUI - page refresh on/off and period wasn't kept after web browser close

+ alarms - possibility to sort alarms

+ alarms - possibility to approve all host alarms

+ probe snmp_generic implemented; this probe based on templates stored in ${AKKADA}/etc/snmp_generic directory; through templates you have the very easy way to add to akk@da support for your SNMP device (if it is not supported by akk@da) without code new probe type; just write simple template for your SNMP device
