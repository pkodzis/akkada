AKK@DA version 0.75-pre1 appliance available!

Submitted by Piotr Kodzis on Wed, 2008-05-07 18:26.
  • news

AKK@DA version 0.75-pre1 appliance is now available. Download links:

AKK@DA_Appliance-0.75-pre1.README.txt 1kB

AKK@DA_Appliance-0.75-pre1.zip 57MB

AKK@DA_Appliance-0.75-pre1.z01 100MB

AKK@DA_Appliance-0.75-pre1.z02 100MB

AKK@DA_Appliance-0.75-pre1.z03 100MB

You need all these files. Version 0.75-pre1 is available only as this appliance. Regular 0.75 will be published soon.

New features and fixed bugs in version 0.75-pre1 (appliance) are described here.

This appliance contains fully functional AKK@DA, but for the performance reasons it should be used rather as a demo. The number of services which it will be able to monitor highly depends on the resources (CPU/RAM) you assign on VMware server for this virtual server.

Have a fun! :)
