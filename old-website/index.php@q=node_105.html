v 0.75

Submitted by Piotr Kodzis on Wed, 2007-09-12 16:35.
  • changes

[* fixed; + added; - removed; @ changed]

+ freshness guard which alarms if an entity data is outdated

+ support for signal TRAP which enables/disables strack traceing to log files

* grep "too many arguments" error fixed

* ssl_generic, tcp_generic, script play procedure error when recieved null

+ probe snmp_generic, added templates for standard RADIUS server authentication and accounting MIBs

+ startup scripts for Gentoo and Ubuntu

+ probe snmp_generic, added templates for monitoring F5 BigIP's chassis fans, power supply, temperature sensors, CPU's fans and temperatures

* ActionsBroker, after removing binding errors like that appeared on console: Use of uninitialized value in subtraction (-) at /akkada/lib/ActionsBroker.pm line 296.

+ module available2 which detects network faults and is looking for a root cause of the network outage; it works on graph based computers network model

+ GUI, tools, subnet_description - tool allows making descriptions of subnets; these descriptions are used when network's graphs are displayed

+ GUI, graphs, context menu - added menus for zooming in/out graphs

+ GUI, Tree - added option to see only group in the tree instead of groups and nodes. in case of big monitored
networks for the performance reason its better to don't see nodes in the tree

+ Gadu-Gadu (polish IM system) notifications of alarms

* GUI, system status, modules' status was shown as "OK" while they were disabled

+ contrib script apc_status.sh for monitoring APC UPS device without SNMP agent using apcupsd daemon (see: http://www.apcupsd.com); by ciechom@eserwer.pl

* Probe ucd_ext, graphs might return errors: Could not parse color in '' at /akkada/lib/RRDGraph.pm line 624.; thanks ciechom@eserwer.pl

+ GUI tool to saerch Cisco switches for half duplex interfaces; additionaly it generates implementation, verification and back out scripts disable auto negotiation on half duplex interfaces and to fix interfaces speed and duplex

+ command line tool windows_service_dus.pl added function to disable unwanted servies in the selected subtree

@ old last check dates presentation in red based on checking period instead of fixed amount of time

* recovery notification wasn't sent in case of calculated status recovering

+ "previous status duration" information added to notification message

+ GTalk notifications of alarms

@ GUI performance‘s improvement of displaying nodes with a big number of services

+ ip address information to mail notification message

+ tool which allows finding MAC address related to ip address across all monitored network

+ tool which allows locate MAC address across all monitored Cisco switches

+ Probe snmp_generic templates for F5 TMM statistics support, profile fastL4 statistics, virtual server state and statistics, pools state and statistics, nodes state, failover status

+ GUI added option to search entities by entity function

+ GUI added option to seaerch entities by collected information

* notifications; recovery notification was sent even if error notification wasn't

+ GUI add new host form, added option to disable ICMP check for the new host

* dashboard, division by zero

@ GUI, graphs title -> added parent entity name

+ support for Powerware UPS battery status, temperature

@ GUI, "system" move from main toolbar at the top into the "dashboard"

+ contrib scripts (/akkada/contrib) to extend snmpd on unix boxes which do: arp monitoring, LVS statistics, postfix statistics and sendmail statistics

@ after changes of the notifications mechanism via GUI, akkada had to be restarted to see them; now this process doesn't need akkada's restart

+ probe cisco_pix_ipsec for monitoring IPSec VPN tunnels state on Cisco PIX firewalls

@ GUI, graphs show/hide cookie persistance didn't work

* SysStat.pm, histogram module, fixed error with "arguments list too long"

+ GUI, dashboard, added "top 10" tab with summary utilization of monitored systems report

@ GUI, entities' context menus - funciton "stop monitor" over the node entity now stops monitoring of the node and all its services; before it stopped only monitoring of the node
