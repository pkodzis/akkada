overview

akk@da is a network monitoring system designed for small and middle-sized computer networks. Its purpose is to quickly detect system or network fault and to display information about detected problem for an administrator. akk@da is designed as a pro-active network monitor. It does not need to be provided with information from any agents, systems, etc. It collects information automatically every single minute (this period can be shortened even to 1 second if needed). Almost all services of the monitored hosts are discovered automatically.
