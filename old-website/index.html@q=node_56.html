v 0.67

Submitted by Piotr Kodzis on Thu, 2006-01-26 21:20. changes

[* fixed; + added; - removed; @ changed]

* probe icmp_monitor.pm kept services in UNKNOWN state if parent node has no SNMP configuration

+ GUI new tab: "utilities" for adding plugins which will do job for you from the akk@da server; startup available plugins which grab from monitored host: routing table, ARP table, TCP connections table, perform ping and nmap TCP ports scan;

+ GUI "stat" tab, context menu on graphs added function "copy" to allow copping graph image to clipboard

+ GUI automatic copy selected text to clipboard (e.g. like in PuTTY)

@ imporeved performance of nm-tree_cache.pl and probes modules by implementing multipple-at-once model of data processing

* it wasn't possible to set parameter on entity if entity had inherited this parameter from its parent

@ entity type "node" cannot inherite parameters from entity type "group"; node parameters are still iherited to all children entities

+ memory control (configuration -> {SystemLimits}) - allows setting memory threshold per each akk@da process; after exceeding defined threshold akka@da will restart affected process

+ probe NTP- responssible for NTP server monitoring

@ GUI node "stat" tab tried to display up time graph for node even if the node didn'thaveconfigured IP address; now it displays up timegraph only if node has configured SNMP

+ GUI "alarms" tab, alarm sounds on/off option

* ICMP monitor paramters nic_ip_max_delay_threshold and nic_ip_max_lost_threshold was ignored

* probe nic - infinite discover if interface with space at the end of the name (e.g. OpenVMS: 'LO IP Interface: LO0, OpenVMS Adapter: , ')

@ GUI "Services options" tab, to imporve performance added checkbox to select entities for update

* hide approved - didn't work for approval made by user with user id 0

+ cfgcheck.pl integrated with etc/init.d/akkada start script

+ cfgfind.pl script for quick locating variables in proper config files and dumping parts of the consolidated configuration

+ cfgdump.pl script to print consolidated configuration

+ cfgcheck.pl script to check config integrity

@ akkada.conf configuration file model changed from one file to multiple files conf.d model

+ GUI audit of mandatory entity changes on "options" tab in log

+ GUI log clear options -> till now there where only option to clear all log; now it is possible to keep last week or last month

+ rights - option to temporary disable selected right

* permissions -> information leak on views

@ GUI "general" tab; "force test" function now forces also entity status recalculation

@ akkada.conf, all shell and perl scripts use env variable $AKKADA which has to point to akk@da root directory and should be set for user akkada

+ security improvements: akkada must be running as its user; suggested: add user akkada with group akkada; more inform in bin/upgrade-0.66-to-0.67.txt file and in documentation in installation procedure;

+ added bin/post_install.sh script

+ GUI "stat" tab, context JavaScript menu sets selected setting in session for persistance

+ probe tcpip added; probe collects TCP/IP stack global statisticks; through this probe you can also see some stack settings on monitored hosts (e.g. TTL, RTO); by default this probe does not raise any alarms; you can enable alarm function when errors in global statistcs are detected (e.g. you can enable alarm for detecting IP hardware error segments); more info in documentation

+ GUI "services options" tab -> function to delete multiple services the once

* GUI entity delete function didn't force parent status recalculation

+ GUI function "approve all" in alarms tab

+ probe bgp_peer added; probe is responssible for monitoring BGP session; it collect statistics and raise alarms if session is in unexpected state or does not exists; more info in documentation

+ GUI option in akkada.conf {Web}->{ConspiracyFile} if defined, it should point to text file readable for apache process; file data format: str1|str2\n
akk@da will exchange str1 with str2 in whole generated HTML code; this operation is done after all generation and is case insensitive, so if you tell akk@da to replace str "td" with "ff" probably you will do not see the proper web page; however if used in proper way this option allows you to keep hidden all your private information; it shouldbe usefull during public presentations or in case you need to show sample akk@da output to someone not from your organization (e.g. send me sample screens with errors ;] )

+ GUI views option in akkada.conf file {Web}->{Tree}->{ExpandViews} if set to 1 akk@da will display views in tree in expandable mode, which means you will be able to expand view and see its entities in tree; be carefull! if you will have too many entities in views it will take much more time to your internet browser to display akk@da web page

* GUI probe cpu linux graph with percentage CPU utilization was displayed as empty in case when one of the CPU tracks was unknown (e.g. SNMP agent didn't show kernel CPU ticks)

* probe hdd, in hdd_threshold_bytes_mode didn't raise alarm when disk was full

+ GUI graphs - graph reload aftet click on them; right mouse button on graph to quick set time options; both in javascript - only graph reloads, not whole page; thanks to Pawel Sobotka for idea ;)

* bug in RRD cache - if duplicated ip addresses in DB (e.g. 2 objects with the same IP - alive router interface and down interface which has the same IP address configured) RRD cache made duplicated updates which generated in log files errors like: illegal attempt to update using time 1136593608 when last update time is 1136593608 (minimum one second step)

* bug in RRD cache which generated 'not a simple integer' RRD errors

+ GUI added navigation caption bar in teeny mode

* memmory leaks in GUI and entities cache for GUI

+ GUI CSS class names has been changed to short 1-2 characters names; it saves a lot of byte from generated HTML output

+ GUI Alarms sound support - grep akkada.conf for "Sound" string; you can configure different sounds for differend alarm type; there is an option to disable sounds and to make infinite sound if there are unacknowleded alarms; if all alarms are ack, sound alarm is not raised

+ GUI CGI::Compress::Gzip support

* nm-icmp_monitor.pl multiple test the same IP addresses if more the one entity has detected the same IP address

* DB queries optimalization

+ GUI entities cache - improve time of web page loading

* bug with rights to comments; right "co" wasn't enaught to create comments, it was neccessery "cm"; now it's fixed, "co" is enaught to write comment, "cm" allows comments delete action

+ akkada.conf {Web}->{Tree}->{TreeLowLevelDebug} option for very log level tree cache debug; usefull for developers if there are rights or conntent problems with cache; if set to 1 low level information from GUI are visible in apache error log and from nm-tree_cache.pl module as warning on the console where nm-tree_cache.pl module was started (to see those messages nm-tree_cache.pl module should be started manualy, not by etc/init.d/akkada script)

+ GUI RECOVERED status support in views

+ GUI ForceIE option added in akkada.conf; default 1; if set to 0 akk@da does not force GUI client to use MS Internet Explorer; please remember some of the akk@da functions works fine only under MS Internet Explorer

* RRD cache and RRDCacheMaxEntriesNotOK behavior in probes nic and ucd_ext

* FormatDispatcher.pm TEXT format dispatcher problem; probe ucd_ext affected

* attempts_retry_interval parameter was automaticaly set

* Entity.pm removed unneccesery SQL select

+ GUI show/hide not monitored entities

+ probe cpu added parameter cpu_stop_warning_high_utilization which disables alarms when cpu high utilization is detected

* GUI views status calculation if member of view was in NOSNMP or UNREACHABLE status

+ GUI clear history log function

* attempts_current_count unexpected behavior when status other then OK

+ GUI function to reset flaps monitor

+ option to disable logging in history error messages changes if entity status wasn't changed to make history databse a little bit smaller (e.g. if you have network interface and you configured akk@da to ignore its operation status, akk@da still logs its error messages changes in history every time the interface changes its status; with dis option you can disable this); global setting => akkada.conf DisableErrorMessageLog; host/service setting parameter disable_error_message_change_log which override global DisableErrorMessageLog

* GUI errors presentation if more then one error on entity was detected

+ GUI confirmations for delete view and clear log operations

* GUI hide approved alarm function didn't keep its settings during browsing entities tree

+ virtual RECOVERED status, which means entity is in OK status not longer then StatusRecoveredDeltaTime in seconds (see akkada.conf); default value 60;

@ GUI session ID moved from URL to coockie

* during entity delete process wasn't deleted entities parameters which caused RRD update errors in nm-icmp_monitor.pl module like: illegal attempt to update using time 1136593608 when last update time is 1136593608 (minimum one second step)

@ GUI URL structure changed. now entity id is always first parameter
