users' guide

AKK@DA 0.75 users' guide

hardware requirements

Fast disks, good CPU and minimum 1 GB of RAM. akk@da checks all services every minute. It is a lot to do, so its processes consume a lot of system resources. Choosing a proper hardware depends on the service count which akk@da will have to monitor. It is strongly recommended to have a separate server for the akk@da system.

For example:

  • PC, Pentium III 800 MHz, 512 MB RAM with IDE disks is able to monitor around 700 services
  • Server HP DL 380, 2 x Pentium 4 2.9 GHz, 2 GB RAM with SCSII disks is able to monitor around 7000 services

FYI: In the case of MS Windows the server automatic discovery process discovers around 80 services, in the case of Unix server ~20 services; in the case of the network device count the number of discovered services depends on the number of interfaces in the box. There is an option to stop monitoring unnecessary services in order to improve performance, if needed.

system requirements

akk@da was developed on Linux OS (Fedora). It was also tested on RedHat, Gentoo and Ubuntu. Additionally the following software has to be installed:

  • MySQL, ver. 4.x or newer (http://www.mysql.com/)
  • Apache, ver. 2.x with mod_perl (http://www.apache.org/)
  • fping (http://www.fping.com)
  • RRDtool, ver. 1.2 or newer (http://rrdtool.eu.org/); compiled with option --enable-perl-site-install (see ./configure --help from RRDtool sources)
  • Perl, ver. 5.8 or newer (http://www.perl.org/); compiled with threads support
  • Perl modules (http://search.cpan.org/) as listed in installation procedure.

Proper time on your OS. It is recommended to use the NTP daemon to keep your OS time up to date. See www.ntp.org for details.

user requirements

akk@da isn't software easy to install and configure . All system modules and configuration files are written in Perl, so you should be familiar with the Perl syntax. Also the knowledge of Apache and MySQL can help you to fix problems with akk@da installation, configuration and usage.

Before you start playing with akk@da, be informed the main configuration file syntax is a complex Perl data structure. If you are not familiar with C or Perl this file may be not human readable for you. But don't give up! To start the system you will not have to do anything except for changing some directories in this file. If you'd like to make some more advanced changes, you'd better learn Perl a little bit ;) akk@da is not resistant for syntax and logical errors in this file - if you screw it up, akk@da will stop working 4U ;)

akk@da GUI supports Microsoft Internet Explorer 6 or later and Mozilla Firefox 1.5 or later. It also works fine with the Opera browser, except for context menus.
