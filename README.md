## Documentation

The complete manual is in [akkada-0.75-users-guide.pdf](akkada-0.75-users-guide.pdf) — installation, configuration and usage.

## Legacy website

Archaeological excavations in the depths of the Web Archive unearthed the remains of the old website, in the [old-website](old-website) folder.

To browse it locally:

```bash
git clone git@github.com:pkodzis/akkada.git
cd akkada/old-website
python3 -m http.server 8777 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8777/> in any web browser.
